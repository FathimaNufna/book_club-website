# City Book Club Website

A simple PHP and MySQL website with a contact form.

## Features
- Home, Contact and Messages pages
- Contact form saves messages to MySQL
- Messages page shows all messages (newest first)
- Styled with external CSS

## Technologies
PHP, MySQL, HTML, CSS, XAMPP

## How to run
1. Copy this folder to xampp/htdocs/bookclub
2. Start Apache and MySQL in XAMPP
3. Import bookclub_db.sql in phpMyAdmin
4. Open http://localhost/bookclub
